# RS School Landing Page

Авторский учебный проект по заданию [Landing Page](https://github.com/rolling-scopes-school/tasks/tree/master/fullstack-engineering/tasks/landing-page) курса RS School Fullstack Engineering.

## Вариант выполнения

Авторский проект — **CarePulse**, лендинг SaaS-платформы для сетей стоматологических клиник.

## Структура репозитория

- Ветка `main` — служебные файлы.
- Ветка `landing-page` — Часть 1 (вёрстка, адаптив, темы).
- Ветка `landing-page-part-2` — Часть 2 (интерактивность на чистом JavaScript).

## Стек

HTML, CSS, JavaScript (без фреймворков и UI-библиотек).

## Часть 2

На чистом JavaScript добавлены:

- бургер-меню (≤768px) с блокировкой прокрутки и закрытием по Escape / ссылке;
- циклический слайдер Stories с кнопками и индикаторами;
- каталог из `js/products.js`: категории, динамические карточки, Show more на мобильных;
- модальное окно карточки с параметрами Plan и Billing и пересчётом цены.
